Use:

material information in H:AT;
conventional tests reported in AU and the relevant conventional-test sections;
reviewer-form information only as supporting interpretation, not as the score itself.

Assign:

0 — No clear Application contribution

The study is not primarily using UT/IRT to evaluate an engineering/material condition.

1 — Limited Application contribution

An application is present, but it is secondary or weakly developed.

2 — Clear Application contribution

UT/IRT is clearly applied to assess materials, conditions, performance or comparison with conventional tests.

3 — Strong Application contribution

The main objective of the study is clearly an engineering/material application of UT/IRT, supported by several application elements such as multiple materials/conditions and/or conventional-test validation.

For UT, analyze primarily:

Assign:

0 — Almost no methodological contribution

The test is merely mentioned or very poorly described.

1 — Basic methodological contribution

2 — Clear Data Analysis contribution

7. REVIEWER ASSESSMENT

Retain:

2 = strong support.

CRITICAL RULE:

Reviewer Assessment must NOT be used to calculate Application, Methodology or Data Analysis Contribution Scores.

Reviewer Assessment is used ONLY as a tie-break criterion when two or more technical contribution scores are tied for the highest value.

Tie-break procedure:

First calculate:
Application Contribution Score;
Methodology Contribution Score;
Data Analysis Contribution Score.
If one score is highest:
assign that category as Primary Contribution;
do NOT use reviewer comments.
If two or three technical scores are tied for the highest score:
read ABK — Key Contribution;
read ABL — Reviewer Notes;
determine which of the tied categories is most strongly emphasized.
Reviewer comments MUST NOT alter the numerical technical scores.
If ABK/ABL still do not resolve the tie:
use the richer technical evidence from the relevant spreadsheet sections;
flag the classification as lower confidence.

FINAL INTERPRETATION PRINCIPLE

Always distinguish:

WHAT IS THE PAPER TRYING TO DO?

→ Application Contribution

HOW WELL IS THE TEST PROCEDURE DEVELOPED/DESCRIBED?

→ Testing Methodology Contribution

HOW ARE THE WAVE DATA TRANSFORMED INTO MECHANICAL/RHEOLOGICAL INFORMATION?

→ Data Analysis Contribution

Within Data Analysis, always distinguish:

HOW WAS THE SIGNAL PROCESSED?

→ Signal Processing

WHAT PROPERTY WAS OBTAINED?

→ Property Complexity

HOW WAS THAT PROPERTY CALCULATED/IDENTIFIED?

→ Identification Method

Do not confuse these concepts.

The classification evaluates the type and strength of contribution documented in the review form, not the intrinsic scientific quality of the original article.

When information is unclear, state:

“Unclear from the review form”

instead of making unsupported assumptions.
